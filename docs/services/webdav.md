# WebDAV

通过 WebDAV 协议把日记同步到网盘，适合坚果云、Nextcloud、群晖等支持该协议的服务。

## 准备工作

以坚果云为例：

1. 登录网页版，进入 **账户信息 → 安全选项**；
2. 在「第三方应用管理」中 **添加应用**，系统会生成一个 **应用密码**；
3. 记下服务器地址、账号与应用密码。

::: warning 使用应用密码
不要把网页登录密码填进第三方应用。坚果云等服务的 WebDAV 需要使用单独生成的应用密码。
:::

## 在 Moodiary 中配置

进入 **设置 → 服务 → WebDAV 同步**：

| 字段 | 说明 | 示例 |
| --- | --- | --- |
| 服务器地址 | WebDAV 根目录 | `https://dav.jianguoyun.com/dav/` |
| 用户名 | 登录账号 | `someone@example.com` |
| 密码 | 应用密码 | 由服务商生成 |

保存后执行一次同步，验证连通性。

## 建议

- 为 Moodiary 单独建一个目录，避免与其它应用的备份混在一起；
- 建议开启[端到端加密](/guide/sync#端到端加密)，这样网盘服务商只能看到密文；
- 免费网盘流量有限，Moodiary 采用增量同步，日常消耗很小。

## 常见问题

- **401 未授权**：用户名或应用密码错误，重新生成应用密码再试。
- **无法连接**：检查地址是否以 `/` 结尾、是否使用了 HTTPS，以及网络是否能访问该服务。
