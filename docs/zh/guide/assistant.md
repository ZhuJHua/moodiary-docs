# AI 助手

Moodiary 内置一个理解你日记的 AI 助手，可以聊天、帮你整理心情、直接检索甚至替你写日记。

## 服务商与端侧模型

### 1. 连接在线服务

支持任意兼容以下协议的服务，包括官方 API 与各类自建网关：

- **OpenAI Chat Completions**
- **OpenAI Responses**
- **Anthropic Messages**

在 **设置 → AI 助手** 中新建服务商，填写[基础地址、密钥与模型](../services/ai)即可。内置了常见服务商的预设，选好填入密钥就能用。

### 2. 端侧模型

除对话所需的服务商外，应用还内置两个**下载后可完全离线**运行的小模型：

- **心情建议**：写作时在本地分析内容并推荐心情；
- **语义搜索**：在设置中启用后，用一句自然语言描述就能按含义找回日记，见[语义搜索](./organize#语义搜索)。

模型在设置中下载，之后不再需要网络，也不会发送任何数据。

::: tip 对话必须走服务商
对话与日记工具调用由你配置的服务商完成，端侧模型不参与对话。想不依赖第三方云服务，可以自建 Ollama、LM Studio 等本地推理服务，见 [AI 大模型](../services/ai)。
:::

## 它能做什么

助手可以调用一组受控工具来操作你的日记：

- 查询与语义搜索日记；
- 创建、更新、删除日记（会明确征求你的确认）；
- 列出分类；
- 记住你告诉它的偏好；
- 在受控沙箱中运行 JavaScript 处理数据。

::: warning
涉及写入与删除的操作都会先向你确认，请留意助手的每一步动作。
:::

## 隐私

- 对话通过你配置的服务商完成，只有你主动发送的上下文会离开设备；
- 心情建议与语义搜索在端侧模型上运行，完全离线；
- 首次使用会展示免责声明，确认后才会启用。
