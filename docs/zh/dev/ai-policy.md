# AI 政策

你可以使用 AI 工具参与 Moodiary 的贡献，但贡献必须有人参与，并由这个人负责。本政策适用于代码、issue、PR 描述、评审回复和评论。

## 规则

1. **你是所提交内容的作者。** AI 辅助写出的改动，每一行你都要理解。评审时你要能不借助工具解释它。提 PR 之前，你要自己运行并测试过；UI 改动要在设备上试过。
2. **不接受自主 agent。** PR、issue 和评论不能由 agent 创建或主导。PR 由你来提，评审意见由你来读，每条回复由你来决定。不要把评审意见丢给 agent 再贴出它的输出，也不要因为工具说改好了就告诉评审者已经改好。
3. **声明 AI 的使用。** PR 模板里有「AI usage」一节。写「None」，或者写明用了哪些工具、用来做什么。
4. **用你自己的话写。** PR 描述、issue 和评审回复必须由你本人写。英语不是母语时，使用翻译工具没有问题，我们也鼓励这样做：先用你的语言写好，再翻译成英文。让模型替你写内容是不允许的。
5. **PR 保持小而专注。** 不要提没人要求的大范围重构、批量重命名或清理。先开 issue。不要提交 agent 的工作文件，比如计划、对话记录或提示词笔记。

## 执行

看起来是低投入或未经验证的 AI 产出的 PR 或 issue，维护者可以不做详细评审直接关闭。比如作者解释不了的代码、与 diff 对不上的描述、答非所问的回复。屡次违反可能导致被封禁。

我们评判的是贡献本身，不是文字风格。英语不完美也没关系。
