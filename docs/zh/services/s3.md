# S3 / MinIO

通过 S3 兼容的对象存储同步日记，适合自建 MinIO、Cloudflare R2、阿里云 OSS（S3 兼容模式）等场景。

## 准备工作

以 MinIO 为例：

1. 部署或购买一个 S3 兼容的存储服务；
2. 创建一个 Bucket，例如 `moodiary`；
3. 为它创建一对 **Access Key / Secret Key**，并授予该 Bucket 的读写权限。

## 在 Moodiary 中配置

进入 **设置 → 服务 → S3 同步**：

| 字段 | 说明 | 示例 |
| --- | --- | --- |
| Endpoint | 服务地址（不含 Bucket） | `https://s3.example.com` |
| Bucket | 存储桶名称 | `moodiary` |
| Region | 区域，部分服务可留空 | `us-east-1` |
| Access Key | 访问密钥 ID | |
| Secret Key | 访问密钥 | |
| 使用 SSL | 是否使用 HTTPS | 默认开启 |

::: warning 最小权限
为 Moodiary 单独创建密钥，只授予目标 Bucket 的读写权限，避免把整台存储的控制权交给一台手机。
:::

## 建议

- 开启 **使用 SSL**，除非你在完全隔离的内网中；
- 搭配[端到端加密](../guide/sync#端到端加密)使用，存储服务商将无法读取内容；
- Cloudflare R2 等服务的 Endpoint 需要带上账户专属前缀，请以服务商控制台给出的值为准。

## 常见问题

- **签名错误 / 403**：检查 Access Key 与 Secret Key 是否成对、是否被撤销，以及 Bucket 名是否拼写正确。
- **Region 不匹配**：部分服务对 Region 敏感，填写服务商控制台标示的区域，MinIO 本地部署通常填 `us-east-1`。
