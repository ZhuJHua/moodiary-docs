# AI policy

You may use AI tools to contribute to Moodiary. A human has to take part in the contribution and own it. This policy applies to code, issues, PR descriptions, review replies and comments.

## Rules

1. **You are the author of everything you submit.** Understand every line of an AI-assisted change. Be able to explain it in review without asking the tool. Run it and test it yourself before you open the PR, on a device for UI changes.
2. **No autonomous agents.** A PR, issue or comment must not be opened or driven by an agent. You open the PR, you read the review, and you decide each reply. Don't feed review comments into an agent and post its output, and don't tell a reviewer something is fixed because a tool said so.
3. **Disclose AI use.** The PR template has an "AI usage" section. Write "None", or name the tools and what you used them for.
4. **Write in your own words.** PR descriptions, issues and review replies must be written by you. Translation tools are fine and expected if English is not your first language: write your text, then translate it. Letting a model write the content is not allowed.
5. **Keep PRs small and focused.** Don't send sweeping refactors, mass renames or cleanup passes that nobody asked for. Open an issue first. Don't commit agent working files such as plans, transcripts or prompt notes.

## Enforcement

Maintainers may close a PR or issue that looks like low-effort or unverified AI output without a detailed review. This includes code the author cannot explain, descriptions that don't match the diff, and replies that ignore the question. Repeated violations may lead to a block.

We judge the contribution, not the writing style. Imperfect English is welcome.
