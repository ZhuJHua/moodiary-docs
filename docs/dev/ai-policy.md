# AI policy

We welcome AI-assisted contributions. Use whatever tools help you write, test, translate or understand the code.

## The one requirement

**A human owns every change.** Before you open a PR, read every line the tool produced. In review, you can explain why the code works the way it does. After it lands, you stay responsible for it: if it causes a problem, you can debug it and fix it.

## Suggestions

- Run and test the change yourself before you open the PR.
- Mentioning the AI tools you used in the PR's "AI usage" section helps reviewers. It is optional.
- Keep the PR focused on one topic.
- Don't commit agent working files such as plans or transcripts.
