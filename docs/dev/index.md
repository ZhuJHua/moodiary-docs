# Contributing

Moodiary is an open-source project, and contributions of every kind are welcome. Bug reports and feature ideas go through [GitHub Issues](https://github.com/ZhuJHua/moodiary/issues/new/choose). Pull Requests branch from `develop` and target `develop`. PR titles follow [Conventional Commits](https://www.conventionalcommits.org/en/v1.0.0/), and both the title and the description are written in English.

The full guide lives in the app repository and is the single source of truth for the development setup, the checks to run before a PR, and the PR conventions:

- [CONTRIBUTING.md](https://github.com/ZhuJHua/moodiary/blob/develop/CONTRIBUTING.md) (English)
- [CONTRIBUTING.zh.md](https://github.com/ZhuJHua/moodiary/blob/develop/CONTRIBUTING.zh.md) (简体中文)

This site lives in the [moodiary-docs](https://github.com/ZhuJHua/moodiary-docs) repository. To fix a page, use the "Edit this page on GitHub" link in the bottom-right corner and open a Pull Request.
